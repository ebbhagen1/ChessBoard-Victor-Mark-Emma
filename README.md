♟️ C# ChessBoard Project

📝 Project Description
This project is a console-based chess board developed in C#. The program allows the user to specify a desired board size, generating a dynamic chessboard pattern. The project focuses on object-oriented programming, clean code structure, and effective team collaboration via Git.

⚙️ System Requirements
The project requires .NET 10 to be installed on your computer.
