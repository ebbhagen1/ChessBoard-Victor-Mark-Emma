# ♟️ C# ChessBoard-projekt

## 📝 Projektbeskrivning
Detta projekt är ett konsolbaserat schackbräde utvecklat i C#. Programmet låter användaren ange en önskad storlek på brädet (mellan 3 och 50), vilket genererar ett dynamiskt schackmönster med `X` och `0` i konsolen. Projektet fokuserar på objektorienterad programmering, ren kodstruktur och effektivt samarbete i team via Git.



## ⚙️ Systemkrav
* Projektet kräver att **.NET 10** är installerat på din dator.



## 🚀 Kom igång (Klona, Bygg och Kör)
Följ dessa steg för att köra projektet lokalt:

git clone https://github.com/ebbhagen1/ChessBoard-Victor-Mark-Emma.git
cd Chessboard-
Dotnet build
Dotnet run
